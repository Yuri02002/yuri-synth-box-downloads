# YURI SYNTH BOX

Free Windows x64 VST3 and standalone synthesizer by YURI Enterprise. The first public release will be labelled **pre-release** so users can help us find DAW-specific issues.

## Download

Use only an explicitly published asset on the [official releases page](https://github.com/Yuri02002/yuri-synth-box-downloads/releases). A draft or an asset named CANDIDATE is not a public release. GitHub's automatic "Source code" archives are not the installer. Check the SHA-256 value published with the exact download.

The Windows installer is **not code-signed**. Windows may show an unrecognized-publisher warning. You can choose not to install; never disable Windows security to run it. The plug-in is free. A donation, if offered later, is optional and never required for the download.

## Feedback / feedback

[Report a bug, DAW problem, idea, or short review](https://github.com/Yuri02002/yuri-synth-box-downloads/issues/new?template=prerelease-feedback.yml). Include the YURI SYNTH BOX version, Windows version, DAW and DAW version (or Standalone), plus steps to reproduce. An optional 1-5 rating is included.

No GitHub account? Email info@yurienterprise.com. Do not post private projects, personal data, passwords, or sensitive logs in a public issue. Send sensitive reports by email instead.

Compatibility outside the environments reported by the owner is not guaranteed. This is a pre-release; we want real user reports so we can improve it.
